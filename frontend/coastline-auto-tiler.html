Proper 8-neighbor auto-tiling for smooth island coastlines

Key Concepts: This system generates coastline tiles for the water adjacent to land, not the land itself. It uses 8-neighbor evaluation to create smooth curves and handles inside corners (concave coastlines) properly. Only water tiles directly adjacent to land get special coastline tiles.
