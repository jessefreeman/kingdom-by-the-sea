❌ Why Traditional Auto-Tiling Fails for Coastlines

  • Pattern Explosion: 2^8 = 256 possible neighbor combinations
  • Wrong Paradigm: Auto-tiling designed for terrain blending, not boundary detection
  • Duplicate Assignments: Different patterns forced to use same tiles
  • No Corner Continuity: Adjacent tiles don't align at pixel level

✅ Marching Squares Solution

  • Only 16 Configurations: Based on 2x2 corner sampling
  • Boundary-Specific: Designed exactly for shape outline detection
  • Pixel-Perfect: Guarantees corner continuity between tiles
  • Proven Algorithm: Used in computer graphics for decades

⚙️ Algorithm Explanation

Sample 2x2 corner configurations instead of 8-neighbors
Map each configuration to one of 16 fundamental boundary types
Generate coastline tiles with pixel-perfect corner continuity
Apply rotations and mirroring for tile variations
Ensure seamless connections between adjacent tiles
